This project was for my CS 478 course during my Spring 2026 semester at the University of Illinois Chicago. I independently developed a multithreaded Android application that simulates a gopher-hunting game where two worker threads compete to locate a hidden gopher within a 10×10 grid using different search algorithms.

The project demonstrates Android development skills including UI design, multithreading, thread synchronization, and inter-thread communication using handlers and messages. I implemented both the front-end and back-end logic, including game flow control, thread management, feedback processing (near miss, close guess, miss, and success), and real-time UI updates.

The app also enforces custom permissions and runs a continuous simulation where both threads operate in parallel until one wins. As required by the course, Claude AI was used as a development assistant to support debugging and guide implementation choices. It was used as a learning tool to improve development efficiency while maintaining a strong understanding of all implemented code.

The complete project is available in Project4.zip. The additional files are the primary source files I contributed to and are separated out for easier viewing and quicker access to the core implementation.
